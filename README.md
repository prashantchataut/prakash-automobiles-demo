# Prakash AutoMobiles — demo

**Live:** https://prashantchataut.github.io/prakash-automobiles-demo/

A read-only snapshot of the Prakash AutoMobiles POS & workshop prototype
(Dhangadhi, Nepal), filled with generated sample data — no real customers.

- Every screen is pre-rendered from a seeded copy of the real app.
- Product and customer search, and the suggested assistant questions, work in the browser.
- Nothing can be saved: sales, payments and edits answer "read-only demo".

The `gh-pages` branch is generated by CI in the private source repository on every
build and replaced each time — do not edit it by hand.
